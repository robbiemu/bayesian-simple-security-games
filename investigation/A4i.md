# A4i · Reduce affine market clearing to one-resource security games

**🟩 Result for the stated scope**

One strictly signed game with one defender resource recovers exact affine-market minimum prices. Unit markets and games with uniform priors and equal gains are polynomial-time Turing equivalent.
