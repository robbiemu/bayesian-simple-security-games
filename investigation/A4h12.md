# A4h12 · Use one-good block solvers for shared buyers and goods

**🟩 Result for the stated scope**

A buyer proxy preserves clearance and turns the viable incidence graph into a goods-interaction graph. The existing block algorithm then handles arbitrary mixed articulations in bounded blocks.
