# Publication record

This is a public working edition of the investigation of Vincent Conitzer’s open problem. The initial commits assemble completed research from 21–22 November 2026. They group material by research question and carry their actual publication-preparation dates. The contribution catalog identifies who proposed a direction, which work followed, and which evidence supports that attribution. A Git author on an import commit identifies the publisher. [Original problem](https://arxiv.org/abs/2610.08796)

The mathematical notes are working arguments. Their terms “proved” and “checked” describe the work reported in those notes. The B3g audit was a separate model-assisted proof check. The general exact polynomial-time equilibrium problem remains open in this investigation.

The Lean package checks library lemmas and examples for the fixed-flow investigation in `LibraryChecks`. The H4 development proves that the executable binary compiler emits one deterministic mean-payoff game with the same decision answer as the source threshold instance. It also bounds the compiler's executed bit cost polynomially in the input length under the stated cost model.
