# L1 — Published Catcher–Evader algorithm

The later B3 investigation gives a superpolynomial iteration lower bound for this continuation in the single-attack model. The literature assessment below records the baseline at the start of the investigation. [Forced flow switches](B3f-forced-flow-switches.md)

The published algorithm gives an exact equilibrium path for the strictly signed subclass, with an exponential worst-case **upper bound on the number of iterations**. The missing bound concerns changes to the attacker best-response graph within a fixed set of defender threshold targets. An exact three-target instance below shows that an attacker edge can enter, leave, and reenter even with that defender set and all target attack totals fixed. I found no published polynomial-time algorithm, intractability theorem, or superpolynomial iteration lower bound for the full model in the search described below. [Conitzer, open problem, §§1–2](https://arxiv.org/pdf/2610.08796) · [Li, Conitzer and Korzhyk, IJCAI 2016, §§6–7, pp. 332–336](https://ijcai.org/proceedings/2016/0054.pdf)

## How the models align

Write $n$ for the number of targets, $k$ for the number of types, $x_t$ for defender coverage, $y_{it}=p_iq_{it}$ for the prior-weighted probability of type $i$ attacking $t$, and $z_t=\sum_i y_{it}$. The feasible marginals are $0\le x_t\le1$, $\sum_t x_t=r$, $y_{it}\ge0$, and $\sum_t y_{it}=p_i$. An attacker row is supported on the maximizers of $a_{it}-d_{it}x_t$. The defender maximizes $\sum_t\beta_t z_t x_t$, since the uncovered payoff term depends only on $y$. The defender marginals lift to a mixed strategy over $r$ distinct targets by the hypersimplex decomposition. Zero-prior types can be omitted during computation and assigned any best response at the returned coverage. [Conitzer, §1](https://arxiv.org/pdf/2610.08796) · [Catcher–Evader, §§2–3.1, pp. 330–331](https://ijcai.org/proceedings/2016/0054.pdf)

The paper's §3.1 allows each type to attack an arbitrary number of distinct targets. Set that number to one. In its CE notation this gives catcher budget $r$, catcher caps $1$, catcher base utility $b_{0t}=0$, catcher delta $d^{\mathrm{CE}}_{0t}=\beta_t$, evader $i$ budget and every evader cap equal to $p_i$, evader base utility $b_{it}=a_{it}$, and evader delta $d^{\mathrm{CE}}_{it}=-d_{it}$. The type-independent uncovered defender payoff is the CE alternating utility $a_{0t}$. The one-attack constraint makes the evader caps redundant once the row sum is imposed. CE in §2 also allows separate site caps, arbitrary fractional budgets, and catcher base utilities. The paper assumes $\beta_t>0$ and $d_{it}>0$, while the open problem uses weak signs. [Catcher–Evader, §§2–3.1, pp. 330–331](https://ijcai.org/proceedings/2016/0054.pdf)

Zero coefficients make the literal logarithms or divisions in the continuation undefined. For purposes of a polynomial-time existence theorem, an exact solver for the strict subclass would suffice for the weak subclass via a separate rational reduction. Increase every $\beta_t$ and $d_{it}$ by a common tiny rational $\epsilon$. From a strict-game equilibrium record each $x_t$'s lower, upper, or interior status and each row's support. In the original game's feasibility LP, fix those bounds and impose equality to the appropriate best-response threshold on the recorded interior coordinates and support edges. Permit an interior coordinate to reach a bound and an edge on the recorded support to have zero mass. The perturbed solution satisfies all original best-response constraints to within $\epsilon$ per row or target, since $x_t,z_t\le1$. The minimum common slack over any such pattern has polynomial bit length at a basic optimum. A uniform determinant bound over the LP templates gives an explicit $\epsilon=2^{-\mathrm{poly}(L)}$, with $L$ the input length, strictly below any positive minimum slack. Solving the pattern LP therefore gives a weak-sign equilibrium exactly. This reduction is an observation for the task.

## Algorithms 1–4 and the iteration bound

For intermediate defender budget $s\le r$, let $\mu_{it}=a_{it}-d_{it}x_t$, $u_i=\max_t\mu_{it}$, $\mu_{0t}=\beta_tz_t$, and $\lambda=\max_{t:x_t<1}\mu_{0t}$. Let $\mathcal A=\{(i,t):\mu_{it}=u_i\}$ be the active attacker edges, and let $B=\{t:x_t<1,\ \mu_{0t}=\lambda\}$ be the open defender boundary. For $s<n$ these are the paper's active edges and open boundary specialized to one attack per type. [Catcher–Evader full version, §6.2, PDF pp. 6–8](https://arxiv.org/pdf/1602.01896v2#page=6)

| Algorithm | Exact operation in the strict, single-attack model |
| --- | --- |
| 1 | Start at $x=0$ and give each type all of its mass on maximizers of $a_{it}$. Repeatedly run 2 and 3, calling 4 when 3 fails, until $\sum_t x_t=r$. |
| 2 | Find a min-cost transportation flow over $\mathcal A$ with row sums $p_i$, column sums $z_t$, optional edge caps $p_i$, and costs $\log d_{it}$. It preserves coverage, target totals, and best responses. With forward weights $\log d_{it}$ and reverse weights $-\log d_{it}$, the residual graph has no negative cycle. |
| 3 | Search for a seed in $B$ whose residual reachability stays inside $B$ on the target side. Run shortest paths from that seed. Set $\gamma_v=\exp(-\operatorname{dist}(v))$ for reachable nodes and zero otherwise. Increase $x_t$ at rate $\gamma_t$ and decrease $u_i$ at rate $\gamma_i$, keeping $y$ fixed. Stop at the first defender budget or target-cap event, or the first new attacker tie. |
| 4 | With $x$ fixed, reroute mass over active edges. Each $t\in B$ sends exactly $\Delta/\beta_t$, so its score falls by the common amount $\Delta$ and $\lambda$ falls to $\lambda-\Delta$. A saturated receiving target may accept any available mass. An unsaturated receiving target below the threshold may accept up to $(\lambda-\Delta-\mu_{0t})/\beta_t$. Maximize $\Delta$ with the paper's upper bound from the closest below-threshold site. |

Algorithm 3 only raises coverage. Lemma 7 shows that a target can enter $B$ once and leave once, when its coverage reaches one. Lemmas 5–6 show that a failed run of Algorithm 3 permits a strict threshold drop in 4, after which either a new target reaches the boundary or Algorithm 3 succeeds. Lemma 8 counts complete superior, active, and inferior edge patterns between changes of $B$, using threshold drops and decreases in flow cost or shortest-path distances. Theorem 5 bounds the outer iterations by $2n+4n\,3^{kn}$. Here each row's threshold is its maximum, so there are only active and inferior edges and the crude pattern space still has $2^{kn}$ possibilities. The paper gives no amortization by individual tie edge. Its roughly linear iteration counts come from experiments on random CE instances with small integer parameters. [Catcher–Evader, §6.2, Lemmas 5–8 and Theorem 5, §§6.3–7, pp. 334–336](https://ijcai.org/proceedings/2016/0054.pdf#page=6)

### Bit complexity of an exact implementation

- **Algorithm 2.** In a residual cycle of length at most $n+k$, the sign of the sum of signed $\log d_{it}$ is the sign of a rational product minus one. Its numerator and denominator have polynomial bit length. Every nonzero simple cycle cost is thus bounded away from zero by $2^{-\mathrm{poly}(L)}$. Compute rational log approximations accurate enough to preserve all strict cycle signs and solve ordinary rational min-cost flow. Any optimal flow for the rational costs is optimal for the original log costs, since an original negative cycle would still be negative. Algorithm 3 can then compare path weights directly by products and recover $\gamma_v$ as the inverse of a rational path product. No exact comparison of arbitrary weighted sums such as $\sum y_{it}\log d_{it}$ is needed.
- **Algorithm 4.** The paper describes binary search over a real $\Delta$. For exact output, maximize $\Delta$ in the rational LP with one variable per residual arc, flow conservation, fixed slope source equalities, and the stated affine receiving capacities. A basic optimum gives the exact breakpoint and a feasible rerouting. In Algorithm 3, skip an inactive-edge breakpoint if its relative rate vanishes or it cannot become tight in the forward direction.
- **Size of iterates.** Choose basic flows or integral flows after common-denominator scaling in 2. The transportation matrix is totally unimodular. In 3, each selected direction and event yields an affine update with coefficients of polynomial bit length, independent of the previous denominator. In 4, the previous state occurs only in the right-hand sides, and a basic solution introduces a determinant factor of polynomial bit length. Starting with a common denominator for the priors, its bit length therefore grows by at most a polynomial in $L$ per iteration. This suffices for polynomial total bit complexity if a polynomial iteration bound is established. It does not give an input-only polynomial bit bound at arbitrary iterations of a potentially exponential path. [Catcher–Evader full version, Algorithms 2–4, PDF pp. 7–8](https://arxiv.org/pdf/1602.01896v2#page=7)

L1a isolates a separate cost of this continuation. A proportional transportation ray forces exponentially many strict Algorithm 4 threshold drops, with the open boundary fixed throughout. [Construction and exact replay](L1a-strict-threshold-drops.md)

## Exact edge-revisit instance

Take $r=2$, targets $A,B,C$, four types of prior $1/4$, and $\beta=(2,4,4)$. Use uncovered defender payoffs zero. The following rows give $a_{it}$ and $d_{it}$ in target order.

| Type | $a_i$ | $d_i$ |
| --- | --- | --- |
| 1 | $(1,0,0)$ | $(12,30,1)$ |
| 2 | $(0,4,0)$ | $(5,31,26)$ |
| 3 | $(3,0,5)$ | $(6,19,31)$ |
| 4 | $(4,1,3)$ | $(23,19,21)$ |

Always test target $A$ first in Algorithm 3. At step 0, each type has a unique best target, giving $z=(1/2,1/4,1/4)$ and all defender scores equal to $1$. Every target stays in $B$ through this trace, so the seed eligibility test succeeds and there is no call to Algorithm 4. An entry such as $AC$ is a two-way tie for a type. The assignment column is the unique output of Algorithm 2 at that step and has one target per type.

To reproduce the trace, calculate the best targets by exact comparison of $a_{it}-d_{it}x_t$. For the displayed assignment, include a reverse arc $t\to i$ of multiplier $1/d_{it}$ on each assigned edge and forward arcs $i\to t$ of multiplier $d_{it}$ on all tied unassigned edges. Start the product at $1$ on $A$, obtain minimum path products by six Bellman–Ford passes over the seven vertices, and take their reciprocals to get rates, with zero for unreachable nodes. Among inactive pairs with $\gamma_i>d_{it}\gamma_t$, the candidate step length is $(u_i-\mu_{it})/(\gamma_i-d_{it}\gamma_t)$. Its minimum, the remaining budget divided by the total coverage rate, and the first unit cap give the displayed step. At step 4 the two possible assignments of types 1 and 3 to $A,C$ form a two-by-two transportation problem. Their swap is strict because $1\cdot6<12\cdot31$. All the other min-cost assignments in the table are forced by row and column totals. The table was checked using exact rational arithmetic.

The edge $(4,C)$ enters at step 1, is lost between steps 3 and 4, and reenters at step 5. At step 3 the payoff on $C$ falls at rate $21\cdot12$ while type 4's best payoff falls at rate $23$. After the swap, the payoff on $C$ falls at rate $21\cdot6/31<23$ and catches up. This rules out a proof that charges each active edge only once per fixed defender boundary or fixed set of attack totals.

## Literature check and next lemma

- **Closest published positive result.** Korzhyk, Conitzer and Parr, IJCAI 2011, §3.2, Theorems 2–3, maintain equilibrium with one complete-information attacker who can attack several distinct sites. They bound the path by $6n$ phases of $O(n)$ arithmetic operations using monotone target states. This applies to $k=1$. With multiple types, one resource per type still allows heterogeneous slopes and separate best-response rows, as the revisit instance shows. [Security Games with Multiple Attacker Resources](https://ijcai.org/proceedings/2011/56)
- **Published reductions.** The Catcher–Evader §4, Theorem 2, strong NP-hardness is for Stackelberg commitment, even with one resource per type. Section 6.1, Theorem 4, reduces minimum-cost fractional matching to equilibrium computation in CE games. The displayed construction permits general edge caps and uses $d_{it}=\exp(w_{it})$ for an input cost $w_{it}$. It is a comparison with a polynomial-time matching problem, and the displayed exponentiation does not give rational bit encodings for general costs. A bit-model specialization is given below. [Catcher–Evader, §§4, 6.1, pp. 332–334](https://ijcai.org/proceedings/2016/0054.pdf#page=4)
- **Subsequent sources checked.** Li's thesis, §§3.5–3.6, reports the same continuation and still poses a polynomial bound as future work. The later resource-graph game FPTAS is for approximate equilibrium with symmetry and bounded treewidth hypotheses. The repeated Bayesian security-game work of Caballero et al. addresses a repeated behavioral decision model. Chen, Deng and Ghosh's matching-market algorithm has a distinct one-to-one supply model and a consistency hypothesis that arbitrary pair-specific affine slopes violate. For example, one buyer may remain indifferent between two items as both prices rise from zero to one, while another with payoffs $4-2x_A$ and $3.5-x_B$ switches preference. None supplies a general exact result for this input model. [Li thesis, chapter 3](https://dukespace.lib.duke.edu/server/api/core/bitstreams/db314ced-bae4-4890-a84f-fb80cd3721ed/content) · [Resource graph games, IJCAI 2018, abstract and §3](https://ijcai.org/proceedings/2018/21) · [Caballero et al., Annals of Applied Statistics, 2024](https://doi.org/10.1214/23-AOAS1786) · [Chen, Deng and Ghosh, §4, Theorem 4.1](https://arxiv.org/pdf/1004.2565#page=9)

**Rational matching comparison.** A direct specialization of §6.1 encodes complete $n\times n$ minimum-cost assignment into the target model with $r=1$, $p_i=1/n$, $\beta_t=1$, $a_{it}=0$, and $d_{it}=1+\eta c_{it}$, where the $c_{it}$ are integer costs after clearing denominators, $W=\max |c_{it}|$, and $\eta=1/[8n(1+W)^2]$. At equilibrium every $x_t>0$. Otherwise all types attack only zero-coverage targets, making the defender's positive coverage a non-best-response. For $n>1$ all coverages are then interior and $z_t=1/n$. Attack optimality gives $d_{it}x_t\ge m_i=\min_s d_{is}x_s$, with equality where $y_{it}>0$. Taking logs supplies dual feasibility and complementary slackness for transportation with costs $\log d_{it}$. Every simple cycle with strictly negative integer cost also has negative log cost, by $|\log(1+w)-w|\le2w^2$ for $|w|\le1/2$ and cycle length at most $2n$. Thus an equilibrium flow minimizes the original costs, and its doubly stochastic scaling yields a minimum-cost perfect assignment via decomposition. All game inputs have polynomial bit length. This is a matching comparison even at $r=1$ and leaves the general complexity question open.

**Suggested next lemma.** In a fixed $B$ phase, outside coverage is frozen and each type's maximum payoff is nonincreasing. Therefore the set of types with any outside best response can only grow during that phase. For a fixed demand graph $D_i=\{t:(i,t)\in\mathcal A\}$, ignore finite receiving capacities outside $B$ in Algorithm 4. The smallest attainable new threshold is the weighted Hall maximum

$$
\max_{\varnothing\ne S\subseteq B}
\frac{\sum_{i:D_i\subseteq S} p_i}{\sum_{t\in S}1/\beta_t}.
$$

To see sufficiency, route all types with no outside demand to targets in $B$ with capacities $\lambda'/\beta_t$ at the displayed threshold $\lambda'$. The Hall inequalities give that flow. Temporarily cap each remaining type's available flow into $B$ by its old in-$B$ mass. Scaling down the old flow into $B$ shows that all target capacities can be saturated under these bounds when row supplies are treated as upper bounds. Consequently augmenting from the mandatory flow fills every column without reducing any mandatory row total. Leave old outside assignments in place and send the remaining flexible mass to outside best responses. If a finite receiving capacity or the outside score bound blocks this reroute in the actual algorithm, a new target meets the defender threshold. The exact next test is whether the maximizing Hall witnesses, or another certificate extracted from their transport flows, have only polynomially many changes across a fixed-$B$ phase. The trace excludes treating each edge's activation as irreversible.
