# L2b Input-only bit bounds for the exact continuation

**Theorem.** In the strict game, use the exact implementation of L2, with a fixed seed order and a fixed coordinate order for choosing a vertex of the optimal Algorithm 4 face. Every retained coverage and attack flow has reduced numerator and denominator lengths polynomial in the original binary input length. This bound is independent of the number of steps. Algorithm 2 can use any exact minimum-cost transportation vertex. The same bound holds for the computed thresholds and the retained column totals.

The two parts use different facts. A coverage step inherits tight paths that express all its moving coordinates with one scalar. A flow reset can be compared with a lexicographic optimum whose outside lower bounds stay fixed for an entire boundary phase. ## Coverage is anchored by tight paths

Assume the positive-prior rows and strictly positive losses and gains of L2. In a successful Algorithm 3 call let \(b\) be the seed, \(S\) its reachable targets, \(U\) its reachable rows and \(A\) the current best-response graph. The normalized flow has no negative residual cycle. Take a shortest-path tree from \(b\) to all reachable vertices. Each tree edge is tight and its two endpoint rates satisfy equality in the relevant loss ratio. It stays tight to the end of the positive step.

The tree gives an expression \(x_t=a_t+b_t x_b\) for each \(t\in S\), and an affine expression for every reached row utility. These are obtained by substituting the equations \(v_i=a_{it}-d_{it}x_t\) along simple paths of length at most the number of vertices. Their coefficients have polynomial input bit length. Every \(b_t>0\), since the rates on the tree are strictly positive.

Consider a maximal stretch of successive successful calls with fixed open boundary \(B\), column totals \(z\), and selected seed \(b\). The reached sets are nested. An old shortest-path tree survives a step, and reachability at its end is invariant under flow reoptimization at the same margins. The old proofs also show that at fixed \(B,z\) an ineligible seed stays ineligible. [Reachability and seed monotonicity](L2-exact-arithmetic-audit.md#non-repetition-with-exact-flow-ties) · [Growing reachable sets](B3b-closed-group-rank.md#thresholds-and-changes-of-seed)

At the end of a completed nonterminal stretch, every coordinate moved in it has an anchor at zero or one through tight input equations. If a cap ended the stretch, the last tree reaches the newly saturated target. Otherwise the old seed must be ineligible at the last endpoint. This holds when Algorithm 4 is about to run, and when a different seed is selected at the same \(B,z\) by the fixed order. There is a residual path from the old seed to a target outside \(B\). That target is at zero or one for the threshold at this endpoint. All arcs of this path and all edges of the last tree are tight at the same endpoint. Because the last tree contains all the targets that moved during the stretch, each has a simple tight path to the box anchor. Algorithm 4 does not change coverage.

In a step within a stretch, any stationary coordinate is an original zero or has the input-only value obtained at an earlier completed stretch. To see that the new moving coordinates also have polynomial bit length, check the event that ends the step.

- A cap or a new tie with both endpoints reached supplies an additional input-only affine equation. In the tie case its coefficient in \(x_b\) is nonzero by the positive catch-up rate.
- A new tie with an unreached vertex must be from a reached row to an unreached good. Its equation uses only one stationary good price, an input-bit rational.
- At the terminal budget, use the affine expressions of the tree and the fixed prices outside \(S\) in \(\sum_t x_t=r\). The coefficient of \(x_b\) is \(\sum_{t\in S} b_t>0\).

Solving the corresponding scalar equation and substituting its result gives the bit bound at each endpoint. Induction over completed stretches justifies the stationary-price assertion and introduces no accumulation from earlier steps. Budget zero needs no step. A terminal cap or tie can itself be used as an anchor if it coincides with the budget.

**Example.** In the four-type edge-revisit instance, the first cap is \(x_A=1\) after eight coverage increases. At that endpoint, row 2's tie gives \(-5x_A=4-31x_B\), and row 4's tie gives \(1-19x_B=3-21x_C\). Substitution recovers the coverage \((1,9/31,233/651)\) from the input payoff equations and the cap. ## Flow resets use a single phase baseline

Fix an open-boundary phase with \(B\) constant. Put \(O=[n]\setminus B\), \(c_t=1/\beta_t\), and let \(l_t\) for \(t\in O\) be the column totals at phase entry. Whether an outside target is full or unsaturated is constant in the phase. For a graph \(A\) and threshold \(\theta\), define a comparison transportation problem with row sums \(p_i\), column totals \(\theta c_t\) on \(B\), lower bounds \(l_t\) on \(O\), and upper bounds \(\theta c_t\) on the unsaturated targets of \(O\). A full target needs no upper bound beyond the total mass. Let \(f(A,\theta)\) be its lexicographic least flow using the fixed Algorithm 4 order on the entries. If column totals are included among the ordered variables they are understood to be sums of the entries. Absent edges can be kept as coordinates fixed to zero.

The invariant is that the actual outside column totals equal those of \(f(A,\theta)\). At phase entry, the lower bounds exhaust all the mass outside \(B\), so they force those totals. Algorithm 2 preserves totals by definition.

For an Algorithm 3 step staying in the phase, use its reached sets \(U,S\). At the old state, \(U\) only demands \(S\) and \(p(U)=\theta c(S)\). Thus the comparison problem already splits into flows on \(U\times S\) and on \(U^c\times S^c\). At the endpoint every row outside \(U\) retains a used option outside \(S\) at its old utility. It cannot demand a strictly rising target of \(S\). So \(S\) still uses exactly the rows of \(U\), even if they have gained new ties elsewhere. The graph on \(U^c\times S^c\) and its margins are unchanged. Lexicographic optimization on that product leaves its outside totals fixed.

For an Algorithm 4 reset that stays in the phase, let \(A\) be its unchanged graph, \(\theta>\theta'\) the thresholds, and set \(f=f(A,\theta)\), \(g=f(A,\theta')\). Both exist. The actual reset is feasible, so every unsaturated outside column's old total \(f_t=z_t\) is at most \(\theta'c_t\). Suppose an outside column \(j\) decreased from \(f_j\) to \(g_j\). Decompose \(g-f\) into signed alternating paths from decreasing columns to increasing columns, together with cycles. A path from \(j\) ends at an increasing outside column \(k\), since every column of \(B\) decreases.

Move a sufficiently small amount forward on that path at \(f\). Its source \(j\) has room above \(l_j\), and its destination \(k\) has room below \(g_k\), which respects the upper bound at \(\theta'\) and hence at \(\theta\). The signed arc directions preserve nonnegativity and all row and \(B\)-column totals. Now move in reverse at \(g\). Column \(k\) has room above \(l_k\), and column \(j\) can grow toward \(f_j\), which respects the tighter upper bound by actual reset feasibility. The two comparison problems therefore admit opposite nonzero perturbations along the same path. One strictly improves the common lexicographic order, a contradiction.

It follows that \(g_t\ge f_t\) for every outside column. Thus \(g\) satisfies the actual reset's lower bounds as well. Since \(g\) minimizes over the larger problem with the phase's lower bounds, the actual reset's fixed-order optimum at \(\theta'\) is \(g\). This proves the invariant.

## Denominator accounting by phases

Take \(D_0\) to be a common denominator for row masses and all phase-entry column totals. A reset that adds no member to \(B\) is followed by a successful step. Its threshold is the successful seed's weighted Hall ratio, hence has polynomial input bit length; the same expression gives zero if the reachable row set is empty. All right-hand sides of the comparison problem at this reset lie on a grid of denominator \(D_0D_\theta\), where \(\log D_\theta=\operatorname{poly}(L)\) accounts for \(\theta'c_t\). Transportation total unimodularity gives the same grid for the lexicographic vertex, including each outside total. This argument uses one \(D_\theta\) for the current threshold, independent of how many earlier resets occurred.

Algorithm 2 restores a transportation vertex at the current row and column totals, so it stays on their common grid. A cap copies the existing totals into the next phase. A reset that adds members to \(B\) can use L2's original single-call determinant bound on the preceding input, multiplying its grid denominator by an integer of polynomial bit length. Each target enters and leaves \(B\) at most once, so there are at most \(2n\) phase changes. The logarithm of the phase baseline grows additively by only a polynomial amount at each change. Coverage, attack entries, and column totals lie in \([0,1]\), so their denominator bounds also bound their reduced numerators. Each retained threshold satisfies \(\theta=\beta_b z_b\) for some open-boundary target \(b\). Its reduced numerator and denominator therefore have polynomial input bit length as well. The claim applies to L2's fixed-order vertex implementation. The comparison argument needs one order for both lexicographic optima. ## Bit time for a run

Reduce the retained rationals between outer calls. Each flow optimization, reset LP, and event calculation then has polynomial-bit inputs and takes polynomial time in the original input length \(L\) by the exact implementation in L2. Reducing the output fractions also takes polynomial time. After polynomial-time preprocessing, \(T\) outer calls take \(T\,\mathrm{poly}(L)\) bit time. This applies to the fixed-order implementation even on the exponentially long threshold-drop runs of L1a.
