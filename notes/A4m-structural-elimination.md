# A4m · Eliminating market coordinates before fixed-point search

Two ways to exploit the buyer–good graph sharpen the exact market algorithms. Pinning a set $B$ whose deletion leaves balanced slopes gives $2^{O(\sqrt{|B|}\log(2+L))}\mathrm{poly}(L)$ bit time using the October deep-point routine. Pinning a vertex cover of size $\tau$ gives a different $2^{O(\tau)}\mathrm{poly}(L)$ bound using the November exact fixed-point corollary. In particular, that route takes polynomial bit time if $\tau=O(\log(2+L))$. Both allow arbitrary binary masses and capacities. [October continuous search](A4m-discrete-contraction.md#continuous-variant-and-the-scope-of-the-comparison) · [November exact rational circuits](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/Strongly-polynomial-linear-programming-November-24-2026/build/contractions.tex#L104-L158)

Use the signed node vector $h=(u,-p)$ of A4f, the physical box $[0,W]$ for buyers and $[-W,0]$ for goods, and let $g_i=m_i$ and $g_j=-c_j$. For an edge $e=ij$, put $A_e=e_i-e_j$ and $B_e=e_i-d_e e_j$, where $e_v$ is the coordinate vector of vertex $v$. The map is the coordinatewise clip of
\[
 h-a R(h),\qquad
 R(h)=g+\varepsilon h-\frac{1}{\varepsilon}\sum_e A_e[b_e-B_e^\mathsf{T}h]_+.
\]
With the A4f choice of step $a$, its $\ell_1$ contraction factor is $q=1-a\varepsilon$. Choose $W$ strictly above the original utility and price bounds and above every positive $b_e$ and $b_e/d_e$. A4d gives the regularization and the final exact support repair. ## A convex quadratic program for a balanced interior

Fix rational coordinates $z$ on $B$, and write $I$ for its complement. Assume every cycle in the induced graph on $I$ has equal alternating slope products. Propagate positive weights $w$ along a spanning forest, starting at one in each component. Require $w_j=d_e w_i$ on edges internal to $I$. The cycle condition makes the propagated weights consistent on all internal edges. Only simple paths are needed, so the products of input ratios have polynomial bit length.

For each edge touching $I$, use $\lambda_e=w_i$ if its buyer is in $I$, and $\lambda_e=w_j/d_e$ if only its good is in $I$. Thus $\operatorname{diag}(w) A_{e,I}=\lambda_e B_{e,I}$, including on edges crossing the boundary. For the unpinned vector $y$ define
\[
 \Phi_z(y)=
 \sum_{v\in I} w_v\left(g_v y_v+\frac{\varepsilon}{2}y_v^2\right)
 +\sum_{e\text{ touching }I}\frac{\lambda_e}{2\varepsilon}
    [b_e-B_{e,B}^{\mathsf{T}}z-B_{e,I}^{\mathsf{T}}y]_+^2.
\]
Then $\nabla\Phi_z(y)=\operatorname{diag}(w) R_I(z,y)$. At the lower face of a coordinate box, both the clipped fixed-point equation and minimization require a nonnegative residual there. At the upper face both require a nonpositive residual, and at an interior coordinate both require zero. Positive diagonal weights preserve these signs. Strict convexity gives a unique minimizer, which is the exact conditional fixed point. Introduce a nonnegative variable for each hinge, bounded below by its affine argument. Minimizing the positive square sets that variable to the hinge. This is a rational convex quadratic program of polynomial size, with an exact polynomial-bit-time solver. All pins presented by the search have polynomial bit length. [Kozlov, Tarasov and Khachiyan, convex quadratic programming](https://www.mathnet.ru/eng/zvmmf5189)

The resulting boundary map is still an $\ell_1$ contraction by conditional cancellation. Run the continuous block search on $B$ using the quadratic program at the bottom. With $r=|B|$, blocks of size at most $b$ give $O(r/b)$ levels for $r>0$. The query count at each invocation is polynomial in $L$. The local deep-point overhead is $2^{O(b\log(2+L))}$ per invocation. For a target full error $e$ and gap $\gamma=1-q$, one level uses conditionally evaluated interior locations accurate to $\gamma^3 e/512$ and dyadic queries of polynomial bit length. There are at most $r$ levels, so accumulated precision remains polynomial. This gives $2^{O((b+r/b)\log(2+L))}\mathrm{poly}(L)$ bit time. Choose $b=\lceil\sqrt r\rceil$, or solve the single quadratic program if $r=0$. Recover the exact rational regularized point using the A4d determinant bound and lift and repair as usual. [Continuous error and block recursion](A4m-discrete-contraction.md#continuous-variant-and-the-scope-of-the-comparison)

A supplied set can be checked by propagation. To find one in polynomial time, propagate weights on any spanning forest of the full graph and take a minimum bipartite vertex cover of the edges that violate the propagated ratios. Deleting that cover leaves only consistent edges. Its size is at most the original vertex-cover size and at most the number of violating edges. For example, on $K_{m,m}$ with unit slopes except one slope of two, choose a spanning tree of unit edges. One pin suffices for $m\ge2$, while the full graph has vertex-cover size $m$. More generally, orient gains $d_e$ from buyer to good and use reciprocal gains on reverse arcs. Balanced cycles then satisfy the biased-graph theta property by multiplication of the three path gains. A cycle membership query multiplies polynomial-bit rationals. If the minimum deletion size is $s$, Lee and Wahlström's approximation finds a set of size $O(s\log(2+s))$ in polynomial time. Taking the smaller of the two computed sets gives both bounds. Their exact finder also gives a way to obtain a minimum set at cost $4^s\mathrm{poly}(L)$. [Lee and Wahlström, Theorems 2 and 3](https://arxiv.org/pdf/1610.06060v2#page=4)

Earlier A4g and A4h already give polynomial algorithms when a fixed number of pins leaves balanced slopes. The conditional quadratic program gives an oracle for the regularized node map at arbitrary pinned values. Using it in the continuous block search yields the stated dependence when the number of pins grows. ### Guess signs only in unbalanced blocks

There is a second polynomial-time case that uses the structure inside each component. Partition $G-B$ into its biconnected blocks, counting bridges as single-edge blocks. Mark the blocks with an unbalanced slope cycle. Let $t_0$ be the maximum, over components of $G-B$, of the total number of edges in the marked blocks of that component. A conditional solve takes $2^{O(t_0)}\mathrm{poly}(L)$ bit time by guessing hinge signs only on the marked edges. The remaining hinges include all edges in the balanced blocks and all edges to the pins.

For a sign guess, let $P$ contain its active edges and $U$ be the edges with unresolved signs. In a marked block take a positive stationary vector for $A_P B_P^\mathsf{T}$ restricted to that block. The active subgraph has arcs in both directions on every edge, so each connected component has such a vector, including isolated vertices. In an unmarked block choose scaling $\pi_i=d_e\pi_j$ on every edge. Glue the local vectors along the block–cut tree. Each new block meets the earlier ones at a single articulation vertex, so one positive rescaling matches its shared value while preserving its equations. Globally this gives $A_P B_P^\mathsf{T}\pi=0$ and $B_{e,I}^\mathsf{T}\operatorname{diag}(\pi)=k_e A_{e,I}^\mathsf{T}$ for each unresolved edge. Here $k_e>0$ also exists automatically on a unary edge to the pins. A rational linear feasibility solve for these homogeneous constraints and $\pi\ge\mathbf1$ supplies a polynomial-bit scaling.

Set $h_I=\operatorname{diag}(\pi)z$ and shift the scaled box to lower bound zero. Eliminate the guessed active flows affinely. The node matrix is $\varepsilon\operatorname{diag}(\pi)+\varepsilon^{-1}A_P B_P^\mathsf{T}\operatorname{diag}(\pi)$. Its symmetric part is positive definite because the Laplacian part has nonpositive off-diagonals and zero row and column sums. Keeping the unresolved flows adds the skew cross blocks $-A_{U,I}$ and $A_{U,I}^\mathsf{T}$ after dividing each edge row by $k_e$. Their flow diagonal is positive. To impose an upper bound, add its nonnegative multiplier to the node residual and make that multiplier complementary to the upper slack. These two additional off-diagonal blocks are also skew. This is a monotone LCP. Minimize its convex quadratic complementarity gap over nonnegative variables and residuals with the guessed sign inequalities. The true pattern has minimum zero and any zero yields the correct conditional solution. Solve components independently. [A4g monotone affine-region solves](A4g-budgeted-support-search.md#testing-affine-regions-of-the-regularized-market)

With $B=\varnothing$ this is polynomial when $t_0=O(\log(2+L))$, even with dense balanced blocks. It uses convex quadratic programming and exact support recovery. For a nonempty $B$, use it at the bottom of the October continuous block search for a bound of $2^{O(t_0+\sqrt{|B|}\log(2+L))}\mathrm{poly}(L)$. The replay includes an unbalanced block and a balanced block sharing an articulation, with pins on both sides. It checks stationarity of the glued scaling and the box complementarity residuals.

## Separators in the integer circuit

Pin a separator of $s$ vertices and solve its remaining components independently for each pin assignment. The rounded lattice update has the same graph locality after any pins, so each component can use its own separator. Applying the block recursion to the induced map on each separator adds a factor of $L^{O(\sqrt s)}$ to the cost of its child solves, plus local search overhead of the same order. All levels use the same mesh. Thus a separator hierarchy gives a bound exponential in $O(\log(2+L))$ times the largest sum of $\sqrt s$ on a root-to-leaf path, with a polynomial factor for the number of pieces. For a planar incidence graph the Lipton–Tarjan algorithm gives separators of size $O(\sqrt m)$ on pieces of size $m$, and child sizes at most $2m/3$. The path sum is $O(d^{1/4})$ for $d$ buyer and good coordinates. This gives $2^{O(d^{1/4}\log(2+L))}\mathrm{poly}(L)$ bit time with arbitrary slopes. [Lipton and Tarjan, planar separators](https://epubs.siam.org/doi/abs/10.1137/0136016) · [Integer elimination and recovery](A4m-discrete-contraction.md#eliminate-blocks-and-recover-the-market-exactly)

## Cut coordinates on a vertex cover

Let $B$ be a vertex cover of size $\tau$ and pin $h_B$. Each vertex outside $B$ is the center of an independent star. Its unsigned scalar $y$ is a utility for a buyer and a price for a good. With $t=\varepsilon^2$, its exact conditional fixed point satisfies
\[
 \sum_{\ell}[z_\ell-f_\ell y]_+\le \sigma+t y,\qquad
 \sum_{\ell}[z_\ell-f_\ell y]_+=\sigma+t y\quad\text{if }y>0.
\]
For a buyer center, $z_\ell=b_\ell+d_\ell h_\ell$, $f_\ell=1$ and $\sigma=\varepsilon m_i$. For a good center, $z_\ell=b_\ell-h_\ell$, $f_\ell=d_\ell$ and $\sigma=\varepsilon c_j$. The choice of $W$ makes the artificial upper bound inactive. The scalar is zero if $\sum [z_\ell]_+\le \sigma$. Otherwise sort the breakpoints $z_\ell/f_\ell$ and solve the affine equation on the prefix containing the root. This also gives an exact polynomial-bit lift at rational inputs.

For a cut $S\subseteq B$, identify $S$ with its intersection with the star's leaves in the next formula. Put $Z_T=\sum_{\ell\in T}z_\ell$, $D_T=\sum_{\ell\in T}f_\ell$ and $F_S=\sum_{\ell\in S}[z_\ell-f_\ell y]_+$. Then
\[
 F_S=\max_{T\subseteq S}\min\left(
 Z_T,
 \min_{V\subseteq S^c}
 \frac{(D_V+t)Z_T-D_T Z_V+D_T\sigma}{D_T+D_V+t}
 \right),
\]
where $S^c$ is relative to the leaves. To see this when $y>0$, take $T_*$ and $V_*$ to be the positive hinge sets inside and outside $S$. For $T=T_*$, $Z_T\ge F_S$ and every fraction is at least $F_S$ because $Z_T+Z_V-(D_T+D_V)y\le\sigma+t y$. Equality holds with $V=V_*$. For any $T$, put $R_T=Z_T-D_T y\le F_S$. Choosing $V=V_*$ makes the fraction a convex combination of $R_T$ and $F_S$. When $y=0$, the anchor $Z_T$ is at most $F_S$ for every $T$. At $T=T_*$ it equals $F_S$, and all the fractions are at least $Z_T$ because $Z_T+Z_V\le\sigma$. This proves the identity on the whole physical boundary box.

Write $\rho=a/\varepsilon$. A star contributes $-\rho F_S$ to the cut sum for a buyer center and $+\rho F_S$ for a good center. Multiplying by the negative sign exchanges max and min. In either case the affine branches of the signed star contribution have coefficients in $[-\rho M,0]$ on $S$ and $[0,\rho M]$ outside $S$, where $M$ is the largest neighboring slope for a buyer center and $1$ for a good center. This uses $D_T,D_V\ge0$. An edge entirely on the boundary contributes zero when both endpoints are on the same side of the cut, and otherwise a signed hinge with the same coefficient bounds for $M=\max(1,d_e)$.

Introduce one coordinate $s_S$ for each subset of $B$, representing the sum of signed physical values over $S$. Keep these coordinates independent for oracle queries. Set $\lambda=\rho M$ separately for each star or internal edge and choose a smaller step $a$ if necessary so that $\sum\lambda\le q$. Add $\lambda s_S$ to every affine branch of that contribution. On physical cut vectors its coefficients in the original boundary values are now between zero and $\lambda$. Any such coefficient vector can be implemented on independent cuts. Sort its distinct positive levels and use the sum of the cut sums of their upper level sets, each multiplied by its level increment. The coefficients on cut coordinates are nonnegative and sum to at most $\lambda$. Taking the stated minima and maxima preserves the same sup-norm Lipschitz bound.

Sum those extended terms, the remaining $(q-\sum\lambda)s_S$, and $-a\sum_{v\in S}g_v$. Each output is now $q$-Lipschitz in the sup norm. On physical vectors it is the cut sum of the unclipped conditional boundary update. To clip a physical coordinate $v$ to $[\ell_v,u_v]$, replace each cut sum containing $v$ with its clip between $s_{S\setminus\{v\}}+\ell_v$ and $s_{S\setminus\{v\}}+u_v$. This update is sup-norm nonexpansive on independent cut vectors. Compose the node clips and clip to a common cut cube $[-\tau W,\tau W]$. The resulting circuit preserves the physical embedding and has contraction factor $q<1$. Its unique fixed point is the cut vector of the true boundary point. [Full-market cut clipping](A4m-extremal-price-interface.md#an-explicit-max-norm-lift-with-all-cuts)

There are $2^\tau$ cut outputs. A star of degree $d$ uses at most $2^{d+1}$ affine branches per cut, and $d\le\tau$. Every coefficient is rational of polynomial bit length, so the full affine/min/max circuit has length $O(4^\tau\mathrm{poly}(L))$. For $\tau>0$, rescale its cube to $[-1,1]$ and apply the November exact rational-circuit corollary as stated. The proved range and norm bounds exclude its counterexample output. Lift the exact singleton values by the independent scalar solves and run A4d's repair LP. The case $\tau=0$ is just the independent solves. A4c's supply enlargement keeps the graph and gives exact minimum prices with one such clearing call and a final circulation. Independent connected components can be handled separately by either structural algorithm, with the largest component's parameter controlling the exponent. ### Extend cuts over small independent components

For a supplied set $B$, let $C$ range over the components outside $B$ and let $e_C$ count its internal edges and its edges to $B$. Take the maximum over an empty collection to be zero. A version using LP evaluations gives $2^{O(|B|+\max_C(e_C+|C|))}\mathrm{poly}(L)$ bit time under the November approximation theorem. For example, it takes polynomial time when $|B|=O(\log(2+L))$ and every remaining component has bounded size.

Fix a component $C$. Give its contribution to the boundary map a self share $\lambda_C$ on every boundary coordinate. Take $\lambda_C$ at least the largest sum of incident boundary shares from this component at any one boundary vertex. Choose the step small enough that these shares and the internal boundary-edge budgets sum to at most $q$. On $B\cup C$, keep only this component's hinges, take the $\lambda_C$ self share on $B$, and keep the usual clipped update on $C$. Use no boundary clipping yet. This map is monotone. Its column sums are at most $\lambda_C$ on boundary inputs and at most $q$ in the interior. Fix two ordered boundary points $x\le x'$ and substitute the corresponding ordered conditional fixed points on $C$. Cancel their interior difference from the column sum bound. The resulting boundary map is monotone and its output sum increases by at most $\lambda_C\|x'-x\|_1$.

For a cut $S$, let $f_S(x)$ be the cut sum of that component map, including its self share. For any $x,x'$ in the physical box, monotonicity applied to $x\vee x'$ gives
\[
 f_S(x')-f_S(x)\le\lambda_C\sum_b (x'_b-x_b)_+
 =\lambda_C\max_{T\subseteq B}\bigl(s_T(x')-s_T(x)\bigr).
\]
For an independent cut proposal $z$, use the extension
\[
 \widehat f_S(z)=\max_{x\text{ in the boundary box}}
 \left(f_S(x)-\lambda_C\max\bigl(0,\max_{T\subseteq B}(s_T(x)-z_T)\bigr)\right).
\]
At $z=s(x')$ the inequality bounds all candidates by $f_S(x')$, and choosing $x=x'$ attains it. Every objective at a fixed $x$ is $\lambda_C$-Lipschitz in the sup norm on $z$, so its maximum has the same bound.

Evaluate the extension by enumerating the component's hinge signs and interior box faces. On each choice, the conditions that the interior be a conditional fixed point and that the choice be realized are linear in the boundary and interior coordinates. They describe exactly that part of the conditional graph, since the interior fixed point is unique. The objective $f_S$ is affine there. Represent the penalty with one variable bounded below by zero and all the cut differences. This gives at most $2^{O(e_C+|C|)}$ rational LPs per component and cut, each with length polynomial in $2^{|B|}$, the market input and the query bits. Sum the extended terms and the remaining boundary terms, and clip as above. The combined oracle is a strict sup-norm contraction with factor $q$, whose fixed point is physical. Use the November location guarantee to recover singleton coordinates within $1/(2Q_h^2)$ in physical units, where $Q_h$ is the A4d rational denominator bound. Continued fractions and the exact conditional solve recover the regularized solution and A4d gives a clearing. This extension uses an LP evaluator in place of the explicit star circuit.
