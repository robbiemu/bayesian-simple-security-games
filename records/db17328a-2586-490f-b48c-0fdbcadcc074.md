This [review follow-up](https://github.com/robbiemu/bayesian-simple-security-games/pull/9#issuecomment-7089815875) exercises the stable-flow path used in the precision-scaling proof. A direct rational-capacity implementation of [Cseh and Matuschke's Algorithm 1](https://arxiv.org/pdf/1309.3701#page=8) checks the price bracket for 16 phases on each large-quota fixture and recovers prices \((1,2)\). An independent residual scan checks stability, and a separate fixture checks an augmentation of \(2^{100}\) along a cycle. The replay uses the unit example's slope-product bound and the ordinal example's exact linear equations.

Run `python3 -B experiments/a4f_binary_quota_replay.py`.
