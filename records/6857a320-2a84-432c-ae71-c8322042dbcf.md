A4h4 counts price plateaus as a capacity varies. This pass uses just the supplied capacity. Clipping works for bounded-size blocks and favorable capacity slack. On supported cores, selected-price queries recover a complete price list without enumerating the branch tables. A three-good example shows why a previously saved Hall cut can miss the only violation. [Clipping](../notes/A4h-supplied-capacity.md#clip-branch-loads-to-the-range-that-can-affect-capacity) · [Exact recovery](../notes/A4h-supplied-capacity.md#exact-candidate-recovery-and-call-count) · [Saved-cut example](../notes/A4h-supplied-capacity.md#one-hall-cut-per-size-and-capacity-can-fail)

All 691,875 comparisons pass in the replay. The unrestricted question is whether a guaranteed polynomial-size list can be generated in polynomial bit time for one supplied market. [Open issue](https://github.com/robbiemu/bayesian-simple-security-games/issues/1)

Run `python3 experiments/market_checks/a4h5_capacity_clipping.py` from the repository root. The handoff replay used Python 3.9.6. [Replay source](../experiments/market_checks/a4h5_capacity_clipping.py)
