An internally disjoint branch attached at one core buyer or good can be represented by its attainable load interval at each boundary quote. For a factorized core, the minimum-load queries give a subgradient for an implicit assignment dual. With polynomial-bit-time conditional branch solvers for the perturbed margins, this yields a polynomial-bit-time algorithm for the original minimum prices and clearing allocation. [Boundary interval](../notes/A4h-mixed-port-composition.md#the-full-interval-at-one-boundary-quote) · [Exact reconstruction and call bound](../notes/A4h-mixed-port-composition.md#polynomial-bit-choice-of-queries) · [Issue #1](https://github.com/robbiemu/bayesian-simple-security-games/issues/1)

Run `python3 experiments/market_checks/a4h9_hybrid_examples.py`. The second example uses an interior load in each of two branches attached on opposite sides of the core. It also checks a separate flow for the original capacities. The replay checks the example, while the interval and rational reconstruction arguments in the note give the general claim for this class.
