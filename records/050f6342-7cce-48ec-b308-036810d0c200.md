The common-offset relations from A4e allow changing only the core coordinates. The surrogate is close enough to unit slopes for the A4a sensitivity estimate. A4h9 supplies the exact frozen-core evaluations, including branches at shared buyers as well as goods. A4c selects the original least prices after one support LP. With structure-preserving slope completions, A1 transfers the strict solver through L4b to a weak-sign game. [Research direction](../DIRECTIONS.md#direction-compose-solvers) · [Core proof](../notes/A4h-core-composition-closures.md#a-common-offset-core-with-single-vertex-branches) · [Weak-sign transfer](../notes/A4h-core-composition-closures.md#transfer-to-weak-losses-and-gains)

The dense diagonal-loss example in the proof has exact offsets on the core and offset-inconsistent private branches. The rational transformation leaves every conditional boundary query exact.

Run `python3 experiments/market_checks/a4h11_offset_core.py` from the repository root. The dense core has exact offsets, a lower bound of $3/2$ for the weighted column-spread sum, and a private branch with alternating intercept sum $1/2$. This version attaches the exact replay and its input data after the [PR review](https://github.com/robbiemu/bayesian-simple-security-games/pull/7#issuecomment-7086828698).
