The [PR #8 review](https://github.com/robbiemu/bayesian-simple-security-games/pull/8#issuecomment-7089066389) states the endpoint support question. For each simultaneous multiplier choice, one weighted assignment represents all prices supporting that choice. A4c's rational log gap argument supplies precision for the integer cut that minimizes the list product under specified residual choices. The ascent record provides reference endpoint prices. A supplied price box can also certify a common matching with two assignments, or exclude an individual edge with one LP. [Proof and obstruction to covering all clearing prices](../notes/A4j-endpoint-support.md)

Run `python3 experiments/a4j_endpoint_support_replay.py`. It tests 7,487 choices on 360 unit markets, 80 price boxes, and 80 residual cuts.
