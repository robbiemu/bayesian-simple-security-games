Collins proposed trying a fractional-cover objective and using the failed Hall tests as feedback. The completed pass gave a one-buyer mismatch for fixed weights and an example where one linear cut cannot remove an infeasible midpoint while keeping both clearing endpoints. Reweighting with a slope-based tie-break gives polynomial work per iteration. The current general upper bound on the number of iterations is exponential. [Original attempt](../records/d995764c-0859-4256-adfa-f89596cc04ab.md) · [Fixed-weight example](../notes/A4e-covering-lp.md#the-weighted-dual-can-miss-clearance) · [Hall-cut example](../notes/A4e-covering-lp.md#failed-hall-tests-and-linear-cuts)

The replay checks all 48 seeded markets with exact arithmetic. The longest of these took two updates. An unrestricted iteration bound or a long family for this particular rule remains open. [Descent argument](../notes/A4e-covering-lp.md#an-exact-descent-rule) · [Open iteration question](https://github.com/robbiemu/bayesian-simple-security-games/issues/2)
