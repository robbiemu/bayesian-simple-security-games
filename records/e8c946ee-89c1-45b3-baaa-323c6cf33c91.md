This [review follow-up](https://github.com/robbiemu/bayesian-simple-security-games/pull/9#issuecomment-7089815875) extends the weighted replay for the ordinal allocation proof. Two asymmetric profiles each have maximum edgewise sum \(99/100\). In the split-support example a single edge reaches that sum with two nonzero ratios. The other example uses all four trades in a nonmutual worst-edge cycle. Ordinal stability and affine clearance agree on all 2,250 feasible allocations tested, of which nine are stable.

Run `python3 -B experiments/a4l_asymmetric_ordinal_replay.py`.
