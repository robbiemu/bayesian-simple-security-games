The initial formalization established exact decision correctness and bounded the length of the binary output. Its work theorem bounded an estimate. At the reviewed PR #11 revision `9d7499ea6904da11b6c89f20b5c442832d26dd51`, the main theorem bounds the work of the same run that parses the input, constructs the arena, and emits the correct binary output. The bound uses the documented binary operation costs.
