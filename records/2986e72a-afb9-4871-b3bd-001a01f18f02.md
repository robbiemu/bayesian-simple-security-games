This version incorporates the endpoint and denominator qualifications from the [PR review](https://github.com/robbiemu/bayesian-simple-security-games/pull/18#issuecomment-7180133711).

For a strictly signed game, use L2's fixed seed order, exact minimum-cost transportation vertices in Algorithm 2, and one fixed lexicographic coordinate order for Algorithm 4. Every retained coverage, attack entry, column total, and threshold has reduced bit length polynomial in the original input length, independently of the call count.

At the end of a completed nonterminal coverage stretch, the moved coordinates have tight paths to zero or unit coverage. A budget-only endpoint uses the budget equation with the affine coverage formulas from the last tree. For flow resets, the phase-entry column totals and row masses supply a common baseline denominator for the phase. Within-phase resets use that baseline multiplied by a factor for the current threshold. Only \(O(n)\) changes of phase can add a determinant factor to the baseline.

A retained threshold is the product of an input gain and a retained column total. Reducing retained fractions between outer calls gives \(T\,\mathrm{poly}(L)\) bit time for \(T\) calls after polynomial-time preprocessing. [Proof and exact tie rules](../notes/L2b-input-only-arithmetic.md)
