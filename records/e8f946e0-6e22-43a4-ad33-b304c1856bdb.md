This result formalizes the H4 written proof. For an explicitly encoded fair-coin reachability game and rational threshold, Lean proves that the graph emitted by the compiler has nonnegative lower limiting mean-payoff value at its designated start exactly when the source value meets the threshold. The semantics allow history-dependent randomized source play, nontermination, and equality. [H4 written proof record](65bf511c-d125-4cec-b570-c8615556ee04.md) · [Source semantics](https://github.com/robbiemu/bayesian-simple-security-games/blob/61f7c15bbd864a626530eb6454af4c28f15421c7/lean/StochasticGames/ReachabilitySemantics.lean) · [Decision theorem](https://github.com/robbiemu/bayesian-simple-security-games/blob/61f7c15bbd864a626530eb6454af4c28f15421c7/lean/StochasticGames/ThresholdReduction.lean#L73)

The binary interface proves input and output decoding round trips, a cubic bound on the length of the emitted bits, and a polynomial bound on work under the stated list-scan and schoolbook-arithmetic charges. The model charges for each cell visited and accounts for the bit lengths of arithmetic operands. [Binary compiler and work bound](https://github.com/robbiemu/bayesian-simple-security-games/blob/61f7c15bbd864a626530eb6454af4c28f15421c7/lean/StochasticGames/BinaryReduction.lean) · [Output length bound](https://github.com/robbiemu/bayesian-simple-security-games/blob/61f7c15bbd864a626530eb6454af4c28f15421c7/lean/StochasticGames/ReductionComplexity.lean) · [Cost model](https://github.com/robbiemu/bayesian-simple-security-games/blob/61f7c15bbd864a626530eb6454af4c28f15421c7/lean/StochasticGames/CompilationCost.lean)

Run from the repository root with Z3 on `PATH`.

```sh
(cd lean && lake build && lake test && lake env lean Replay/H4Axioms.lean)
python3 -B experiments/h4_lean_replay.py --systematic 2
```

The build and tests passed. The audited dependencies are drawn from `propext`, `Classical.choice`, and `Quot.sound`. The replay passed on all 3,634 Lean-emitted and decoded tables, with 2,136 YES and 1,498 NO. For `closed-third-equal`, the binary route emits 185 vertices and 330 arcs, matches the typed Lean table, and rejects input and output with trailing bits. The Python compiler separately passed all 3,634 certificate and graph-only checks. [Axiom check](https://github.com/robbiemu/bayesian-simple-security-games/blob/61f7c15bbd864a626530eb6454af4c28f15421c7/lean/Replay/H4Axioms.lean) · [Binary replay](https://github.com/robbiemu/bayesian-simple-security-games/blob/61f7c15bbd864a626530eb6454af4c28f15421c7/experiments/h4_lean_replay.py)
