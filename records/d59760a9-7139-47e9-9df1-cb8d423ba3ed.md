The Python program implements the grouped quota sweep, compressed weighted quote search, and exact repair of the [Lean solver record](e92d96c3-abed-4607-a2e3-a98e82f2a06c.md). It accepts rational JSON and outputs coverage, conditional attack distributions, and a sparse defender lottery. Python computes the repair displacement by rational elimination. The Lean correctness and work theorems apply to the Lean solver. [Solver and replay commands](../lean/Kintali/README.md#python-implementation)

After building the Lean library, run `python3 -B experiments/kintali_replay.py --systematic` from the repository root. The Python and Lean compact outputs agreed on all six shared fixtures and passed independent exact best-response checks. The Python replay also checked 224 systematic inputs and their lottery marginals, including endpoint cases and cost ties. Separate fixtures cover a nonzero projection and a default search that clears after one blocker update. [Replay harness](../experiments/kintali_replay.py)

The Lean search replay includes the crossed-holdings example from the review of PR #15. It verifies that the executable trial rejects its allocation while a reassignment satisfies the exact rows for the same pattern. [Lean search replay](../lean/Replay/KintaliSearch.lean)
