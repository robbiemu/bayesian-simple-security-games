The B3f parametric assignments are forced on disjoint budget intervals. An extra degree-one buyer keeps the deletion-matching ascent running while the balanced core visits those intervals. The path splits preserve the projected core matching and its product. A price bound puts all expanded goods in the same reached-set phase before the first witness. The last buyer's deletion minimum therefore takes superpolynomially many distinct values in that phase on binary inputs of polynomial size. The scope is the deletion-matching ascent in the specified insertion order. The near-factorized theorem computes the endpoints in polynomial bit time. [Proof and scope](../notes/A4j-forced-deletion-switches.md) · [B3f forcing argument](../notes/B3f-forced-flow-switches.md#why-every-equilibrium-uses-the-prescribed-assignment) · [Gajjar and Radhakrishnan, Lemma 14](https://arxiv.org/pdf/1811.05115#page=13)

The split four-type fixture has 28 goods and returns three forced products in one phase, with two internal updates and ten updates in total. The chain follow-up points to the same distinction between available products and successive minima, using a different incidence construction.
