For a strictly signed game, use L2's fixed seed order, exact minimum-cost transportation vertices in Algorithm 2, and one fixed lexicographic coordinate order for Algorithm 4. Every retained coverage, attack entry, column total, and threshold has reduced bit length polynomial in the original input length, independently of the call count.

Successive coverage steps with the same margins and seed inherit a tight tree. When that stretch ends, its moved coordinates have tight paths to a zero or unit coverage. For flow resets, compare lexicographic optima using the outside lower bounds at phase entry. A decrease of one outside total would admit opposite feasible signed-path perturbations at the two optima, one of which improves the common order. This yields a common rational grid per phase. Only $O(n)$ phase changes can require an additional determinant factor.

The conclusion uses the published continuation's update rules. The fixed lexicographic order is used when comparing the two transportation optima. [Proof and precise tie rules](../notes/L2b-input-only-arithmetic.md)
